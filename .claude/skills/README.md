# Project skills

Installed from https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
(plugin `ui-ux-pro-max` v2.13.0, commit 477bcb2, MIT licence) on 2026-10-07.

| Skill | Use |
|---|---|
| `ui-ux-pro-max` | UI/UX design intelligence: styles, palettes, font pairings, UX rules, stack guidelines (searchable local database) |
| `design` | Brand identity, design tokens, logos, CIP, icons, social images |
| `design-system` | Token architecture, component specs, slide generation |
| `ui-styling` | shadcn/ui + Tailwind styling |
| `brand` | Brand voice, visual identity, style guides |
| `banner-design` | Banners for social, ads, web heroes, print |
| `slides` | HTML presentations with Chart.js |

Search scripts need Python 3. Logo/image generation in `design` needs your own
`GEMINI_API_KEY`, `ATLASCLOUD_API_KEY` or `MUAPI_API_KEY`.
To update: re-copy `.claude/skills/` from the upstream repository.
